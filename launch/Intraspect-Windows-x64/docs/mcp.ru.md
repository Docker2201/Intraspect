# Подключение ИИ через MCP

[← На главную](../README.ru.md)

MCP позволяет нейросети читать открытую программу, ошибки, настройки и инструменты, получать изображения 2D/3D. При полном доступе она также может править NC и управлять циклом. Отдельный MCP-сервер, Python или Node.js для Intraspect устанавливать не нужно.

## Codex или Claude Code

1. Откройте Intraspect и нужную NC-программу.
2. В меню выберите **МСП → Окно подключения**. В английском интерфейсе меню называется **MCP**.
3. Нажмите **Подключить нейросеть**. Intraspect запустит встроенный сервер и добавит подключение в существующие настройки Codex и Claude Code. Рядом будет результат для каждого клиента.
4. Перезапустите ИИ-клиент. Intraspect оставьте открытым.
5. Попросите: **«Через MCP Intraspect прочитай текущую программу, проверь ошибки и покажи 3D. Пока ничего не меняй»**.

![Окно подключения MCP в Intraspect](images/mcp.png)

На скриншоте сервер выключен: это исходное состояние. После подключения над кнопкой появится порт и число вызовов, ниже — журнал работы.

**«Не установлен»** означает, что программа не нашла файл настроек клиента. Сначала запустите и настройте сам Codex или Claude Code, затем повторите подключение. Claude Code и Claude Desktop — разные клиенты; автонастройка рассчитана на Claude Code и Codex.

## Что разрешить

- **Без галочки «Разрешить менять…»** — чтение программы, инструментов, ошибок и изображений.
- **С галочкой** — также изменение NC, настроек, инструментов и управление циклом (запуск, пауза, переход к кадру).
- **«Включать сервер вместе с программой»** — не нужно включать MCP вручную при следующем запуске.
- **«Выключить сервер»** — прекращает подключение. Закрытие окна настроек само по себе сервер не выключает.

Примеры запросов:

> Найди ошибки в текущем G-code и объясни, на какой строке они находятся.

> Прочитай состояние остановленного 3D-цикла: активные T/D, кадр, координаты и время инструмента. Получи снимок текущего окна.

> Сравни радиусы из шапки программы с библиотекой. Сначала перечисли расхождения, ничего не меняй.

## Другой MCP-клиент

Нужна поддержка **HTTP MCP**. Скопируйте адрес кнопкой **«Скопировать адрес»** и вставьте его как URL сервера `intraspect` в клиенте. Обычно адрес имеет вид `http://127.0.0.1:8722/mcp?key=ВАШ_КЛЮЧ`, но используйте значение именно из своего окна.

Адрес содержит ключ доступа. Не публикуйте его и не добавляйте в скриншоты. После кнопки **«Новый ключ»** нажмите **«Прописать заново»** и перезапустите клиента.

Сервер доступен только на этом компьютере (`127.0.0.1`). Облачный чат без локального MCP-клиента к нему напрямую не подключится. Сам Intraspect работает без интернета; выбранная нейросеть может отправлять прочитанные данные своему провайдеру.

## Не подключается

| Сообщение / симптом | Что проверить |
|---|---|
| Сервер выключен | Нажмите **Подключить нейросеть** |
| Порт занят | Остановите второй экземпляр Intraspect либо выберите свободный порт, затем подключите заново |
| Клиент не видит инструменты | Перезапустите клиент после изменения настроек |
| Неверный ключ | Заново скопируйте адрес или нажмите **Прописать заново** |
| Нет разрешения на изменения | Включите полный доступ, если действительно хотите правки |
| Нет снимка текущего цикла | Сначала откройте **3D симуляцию**; для снимка используется именно открытое окно |

Для диагностики доступны `get_program`, `check_program`, `get_settings`, `get_tool_library`, `get_toolpath`, `render_graph`, `render_3d`, `get_simulation_state` и `render_simulation_view`. Изменения: `set_program`, `set_settings`, `save_tool`, `remove_tool`, `control_simulation`.
