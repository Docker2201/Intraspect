# Первый запуск

[← На главную](../README.ru.md)

## Скачать и открыть

Нужна Windows x64. Скачайте [готовый ZIP](https://github.com/Docker2201/Intraspect/releases/latest/download/Intraspect-Windows-x64.zip), выберите **«Извлечь всё»** и откройте `Intraspect.exe`. Не запускайте EXE прямо из архива и не переносите его отдельно от папок `app` и `runtime`.

Подойдёт обычная папка с правом записи или флешка. Установка Java, Python, Git или Visual Studio для запуска не требуется.

## Первая деталь

1. **Файл → Открыть** → `samples/first-part.nc` из распакованной папки.
2. Если появилась ошибка отсутствующего **T1 D1**, откройте её и примените предложенное добавление инструмента. Либо добавьте T1, кромку D1 в **настройки → Инструменты**. Для учебного примера подойдёт чистовой резец, радиус вершины 0,4 мм, позиция 3, длины X/Z — 0.
3. Нажмите **СТАРТ** — появится траектория. Для двухканальной программы дополнительно предлагается выбрать, какие каналы отрисовывать.
4. Нажмите **3D симуляция**. **3D** показывает результат; **Цикл** — движение инструмента и снятие материала. Кнопки ▶, паузы, шага и скорости управляют просмотром.

![Редактор и 2D-график учебной детали](images/editor.png)

В примере заготовка Ø80 × 160 мм. Размеры берутся из `WORKPIECE`, координата X задана диаметром (`DIAMON`). Это учебная программа для просмотра, не программа для запуска на станке.

![3D учебной детали](images/simulation.png)

## Своя программа

Сначала выберите станок в **настройках**: горизонтальный для осей или карусельный для вертикальной обработки. Проверьте размеры заготовки, смещения G54… и библиотеку инструментов именно этого режима. Номер **T**, кромка **D**, радиус, позиция и длины должны соответствовать вашей оснастке.

Если программа использует внешние переменные, откройте **Параметры → Программа параметров…**. Для комплекта «параметры + два канала первой стороны + два канала второй стороны» используйте **Файл → Открыть набор файлов…**. Оба канала обрабатывают общую заготовку; в цикле двух сторон предусмотрен переворот.

Красное сообщение означает проблему, которую нужно исправить. Жёлтое — предупреждение или допущение модели. Например, без точных данных резца нельзя достоверно проверить его контакт с деталью.

## Где что включается

| Нужно | Действие |
|---|---|
| Тёмная тема | **Тема → Чёрная тема** |
| Другой язык | **Язык**, затем перезапуск |
| Крупнее интерфейс | **+ / −** в строке меню |
| Изменить геометрию и инструменты | **настройки** |
| Показать траекторию в 3D | **Траектория** в окне 3D |
| Подключить ИИ | [Инструкция MCP](mcp.ru.md) |

## Если не запускается

- Проверьте, что ZIP распакован полностью: рядом с EXE есть `app` и `runtime`.
- Запустите `Run_with_log.cmd` из папки релиза. Журнал — `intraspect-start.log` рядом с EXE.
- При обращении в [Issues](https://github.com/Docker2201/Intraspect/issues) укажите версию, действие перед ошибкой и приложите журнал без личных данных. Ключ MCP присылать не нужно.
